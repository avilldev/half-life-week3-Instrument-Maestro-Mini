# Maestro Mini

<img width="1534" height="951" alt="Screenshot 2026-10-25 170543" src="https://github.com/user-attachments/assets/ff909be9-c8af-417e-91b7-9bb85e831739" />

The Maestro Mini is a device that can give you all the notes in an octave and can also play a tune! It is useful to use in tuning and ear training.

## Components

* **Microcontroller:** Seeed Studio XIAO ESP32-C3
* **I/O Expander:** MCP23017
* **Audio Output:** PAM8302 Audio Amplifier
* **Display:** 0.96" OLED
* **Inputs:** 10x Cherry MX Mechanical Switches
* **Passive Components:**
* 2x 4.7kΩ resistors (I2C pull-ups)
* 1x 1kΩ resistor and 1x 100nF ceramic capacitor (audio smoothing filter)
* **Base:** Custom PCB
